# Temperature Rainfall Analysis Adelaide

## Project Overview
This project investigates the statistical relationship between temperature and rainfall trends in Adelaide, South Australia using historical climate data collected from the Bureau of Meteorology (BOM).

## Dataset
Source: Australian Bureau of Meteorology (BOM)

Time Period:
1995–2026

Variables:

Mean Maximum Temperature (°C)

Monthly Rainfall (mm)

## Methods Used
Univariate Analysis 

Bivariate Analysis

Correlation Analysis

Linear Regression

Residual Diagnostic Analysis

## Repository Structure

### data/

### code/

### plots/

## Key Findings
Increasing temperature trends observed
Decreasing rainfall patterns identified
Negative relationship between temperature and rainfall
